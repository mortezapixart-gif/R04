# ساخت فایل نصب ویندوز (Setup.exe)

این راهنما نشون می‌ده چطور از این پروژه، یک فایل نصب واقعی (`RocketGCS-Setup.exe`)
بسازید که روی هر ویندوزی -- **بدون نیاز به نصب پایتون یا هیچ کتابخونه‌ای** -- قابل
نصب و اجراست.

**نکتهٔ مهم:** این کار باید روی یک سیستم **ویندوزی** انجام بشه (نه لینوکس/مک)،
چون فایل exe ساخته‌شده مخصوص همون سیستم‌عاملیه که ساختش کردید. یک بار که
`RocketGCS-Setup.exe` رو ساختید، همون فایل رو می‌تونید روی هر ویندوز دیگه‌ای
(بدون نیاز به تکرار این مراحل) نصب کنید.

---

## پیش‌نیازها (فقط روی سیستم شما که می‌سازید، نه سیستم کاربر نهایی)

1. **پایتون ۳.۱۰ یا بالاتر** روی ویندوز نصب باشه — از [python.org](https://www.python.org/downloads/)
   (هنگام نصب، تیک «Add python.exe to PATH» رو بزنید)
2. **Inno Setup** (رایگان) — از [jrsoftware.org/isinfo.php](https://jrsoftware.org/isinfo.php)
   (فقط برای مرحلهٔ دوم -- ساخت فایل Setup.exe نهایی؛ برای تست سریع بدون
   Setup.exe لازم نیست)

---

## مرحلهٔ ۱: ساخت نسخهٔ اجرایی (PyInstaller)

1. این پوشهٔ پروژه (`RocketGCS`) رو روی ویندوز کپی کنید.
2. داخل همون پوشه، روی فایل **`build.bat`** دوبار کلیک کنید (یا از Command
   Prompt داخل همون پوشه اجراش کنید).
3. صبر کنید (بار اول ممکنه چند دقیقه طول بکشه چون PySide6 حجم بالایی داره).
4. وقتی تمام شد، پوشهٔ `dist\RocketGCS` ساخته می‌شه.
5. برای تست: داخل `dist\RocketGCS`، فایل `RocketGCS.exe` رو اجرا کنید --
   باید دقیقاً مثل حالت `python main.py` باز بشه (با صفحهٔ خوش‌آمدگویی و
   موزیک).

اگه همین‌جا متوقف بشید، همین پوشهٔ `dist\RocketGCS` رو می‌تونید فشرده (zip)
کنید و برای هرکسی بفرستید -- کافیه فایل zip رو باز کنه و `RocketGCS.exe` رو
اجرا کنه (بدون نیاز به «نصب» واقعی). اما برای یک تجربهٔ حرفه‌ای‌تر (آیکون
روی دسکتاپ، ثبت توی «Add/Remove Programs»، دکمهٔ Uninstall)، مرحلهٔ ۲ رو هم
انجام بدید.

---

## مرحلهٔ ۲ (اختیاری ولی توصیه‌شده): ساخت فایل نصب واقعی با Inno Setup

1. Inno Setup Compiler رو باز کنید.
2. فایل `installer\setup.iss` رو باز کنید (از داخل همین پروژه).
3. روی دکمهٔ **Compile** (یا کلید F9) بزنید.
4. خروجی نهایی اینجا ساخته می‌شه: `installer\output\RocketGCS-Setup.exe`

همین فایل `RocketGCS-Setup.exe` رو می‌تونید به هر کسی بدید. وقتی اجراش کنه:
- یک ویزارد نصب معمولی (فارسی/انگلیسی) باز می‌شه
- می‌تونه محل نصب رو انتخاب کنه
- آیکون توی «Start Menu» و (اختیاری) روی دسکتاپ ساخته می‌شه
- توی «Add or Remove Programs» ویندوز ثبت می‌شه و دکمهٔ Uninstall داره

می‌تونید از خط فرمان هم بسازیدش (بدون باز کردن رابط گرافیکی Inno Setup):
```
iscc installer\setup.iss
```

---

## نکات مهم فنی (برای اطلاع، نیازی به کاری نیست)

- **فونت، لوگو، و موزیک** به‌درستی داخل exe نهایی بسته‌بندی می‌شن (پوشهٔ
  `assets` همراه exe کپی می‌شه) و مسیرشون طوری در کد نوشته شده که چه با
  `python main.py` چه به‌صورت exe فریزشده، درست پیدا می‌شن.
- **آرشیو پروازها** (فایل‌های ذخیره‌شدهٔ داخل برنامه) داخل پوشهٔ نصب ذخیره
  نمی‌شن (چون اگه برنامه توی `C:\Program Files` نصب بشه، کاربر عادی بدون
  دسترسی ادمین اجازهٔ نوشتن اونجا رو نداره) -- به‌جاش توی
  `%APPDATA%\RocketGCS\flight_archive` ذخیره می‌شن که همیشه قابل‌نوشتنه.
- حجم نهایی exe به‌خاطر PySide6/pyqtgraph/matplotlib/pandas معمولاً بین
  ۲۰۰ تا ۴۰۰ مگابایت می‌شه -- این طبیعیه و مربوط به کتابخونه‌هاست، نه کد
  خود پروژه.
- اگه بعداً حالت آموزشی رو هم به‌عنوان یک میان‌بر جدا خواستید (`main_demo.py`)،
  می‌تونید یه exe دوم مشابه همین با `pyinstaller` برای اون هم بسازید و یک
  آیتم دیگه به `[Icons]` توی `setup.iss` اضافه کنید -- ولی چون حالت آموزشی
  الان مستقیم از داخل خود برنامهٔ اصلی (انتخاب «پورت فرضی» در صفحهٔ ارتباط)
  در دسترسه، معمولاً نیازی به این کار نیست.

---

## اگه به مشکلی خوردید

- **آنتی‌ویروس فایل exe رو مسدود می‌کنه:** طبیعیه -- چون فایل امضای دیجیتال
  (Code Signing Certificate) نداره، خیلی از آنتی‌ویروس‌ها با فایل‌های exe
  ناشناس محتاط‌ان. راه‌حل واقعی، خرید یک گواهی امضای کد (هزینه داره) یا
  افزودن استثنا (Exception) در آنتی‌ویروس موقع تست‌ه.
- **exe خیلی کند بالا میاد:** طبیعیه، مخصوصاً بار اول بعد از نصب (آنتی‌ویروس
  همهٔ فایل‌های DLL رو اسکن می‌کنه). دفعات بعد سریع‌تره.
- **پیام `Failed to execute script`:** معمولاً یعنی یه import داخل کد پیدا
  نشده. فایل `dist\RocketGCS\RocketGCS.exe` رو یک بار از Command Prompt
  اجرا کنید (نه دابل‌کلیک) تا پیام خطای کامل رو ببینید، و بعد اون ماژول رو
  به لیست `hiddenimports` داخل `RocketGCS.spec` اضافه کنید.
